Contributing to Gayatri-Demo

Thank you for contributing to Gayatri-Demo.

Getting Started

Before making changes, review the project documentation and understand the purpose of the component you plan to modify.

For local development:

Clone your fork of the repository.
Create and activate a Python virtual environment.
Install the required dependencies.
Run the startup check before making changes.
Make a focused change related to the contribution you are working on.
Making Changes
Keep changes small and focused.
Follow the existing project structure and documentation.
Avoid modifying unrelated files.
Test your changes before submitting them.
Update documentation when your change affects project usage or setup.
Pull Requests

When your changes are ready:

Commit the changes with a clear commit message.
Push the branch to your fork.
Open a Pull Request against the main branch of the upstream repository.
Clearly describe what was changed and why.
Mention any testing or verification performed.
Contribution Guidelines

Please keep contributions consistent with the existing project structure and maintain clear, readable documentation.
